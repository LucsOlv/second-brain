# Templates

Templates prontos para uso com o plugin `Templater`.

## Pasta principal

- `00-Templates/Templater`

## Estado atual do vault

- O plugin `Templater` ainda nao esta instalado neste vault.
- Os arquivos abaixo ja estao prontos; quando instalar o plugin, basta apontar a pasta de templates para `00-Templates/Templater`.

## Observacoes

- Se a nota nascer como `Untitled`, varios templates vao renomear o arquivo automaticamente.
- Os templates usam prompts para preencher campos importantes, como projeto, prioridade, area, source e datas.
- `Hub.md` fica disponivel para colecoes curadas, como o hub de resumos do ONFIAP.
- Ver tambem `00-Templates/Templater Setup.md` para a configuracao exata do plugin.
