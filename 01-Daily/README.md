# Daily Notes

Notas do dia a dia. Cada arquivo corresponde a uma data e deve registrar o que foi vivido de fato, nao servir como hub de todos os projetos ativos.

## Template

```yaml
---
title: DD de mes de AAAA
date: YYYY-MM-DD
day:
type: daily
energy:
mood:
stress_level:
sleep_hours:
exercise:
---
```

## Estrutura Recomendada

- `Resumo do Dia`
- `Tarefas de Hoje`
- `Insights`
- `Estudos`
- `Saude Mental`
- `Acao para Amanha`
- `Ligacoes Relevantes` apenas se o corpo da nota nao deixar a navegacao clara

## Regras

- Nome do arquivo: `YYYY-MM-DD.md`
- Linkar apenas tarefas, projetos, pessoas e referencias realmente envolvidos no dia
- Preferir `daily -> task` em vez de listar todos os projetos ativos no rodape
- Se algo exige continuidade, mover o contexto para a nota da tarefa ou do projeto
- Evitar links fixos para MOCs em toda daily
- Omitir secoes de ligacoes quando elas so repetirem links que ja estao no texto
